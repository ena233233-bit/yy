# Galgame 图片资源

把你自己的图片上传到这个文件夹，然后在 `galgame/index.html` 里的 `ASSETS` 对象中填写文件名。

建议文件：

- `bg-rain.jpg`：背景
- `bg-room.jpg`：背景
- `bg-roof.jpg`：背景
- `hero.png`：角色立绘，建议透明背景 PNG
- `friend.png`：角色立绘，建议透明背景 PNG
- `cg-window.jpg`：CG
- `cg-ending.jpg`：CG

你也可以使用别的文件名，只要同步修改 `ASSETS` 中对应路径即可。

立绘建议：透明 PNG；背景/CG 可以用 JPG、PNG 或 WebP。GitHub Pages 会直接按相对路径加载这些图片。
